# BrewLite

Ứng dụng đặt cà phê không dùng tiền mặt (Bài tập lớn Công nghệ Phần mềm).

## Công nghệ
- Frontend: Next.js
- Backend: NestJS

## Cách chạy

Backend (http://localhost:3001):
```
cd backend
npm install
npm run start:dev
```

Frontend (http://localhost:3000):
```
cd frontend
npm install
npm run dev
```
